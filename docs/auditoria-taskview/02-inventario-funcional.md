# 02 — Inventario funcional

Base: commit `b5a7e65`, lectura estática del código activo. Los endpoints son montajes de `api/src/routes/index.ts` más rutas activas de cada archivo Routes; no se contabilizan rutas comentadas. Las tablas proceden de esquemas y SQL locales. Las funciones no se probaron con usuarios reales.

Convenciones para abreviar rutas verificables: **F** = `web/src/components/features/`; **S** = `web/src/stores/`; **B** = `api/src/tv-modules/`; **D** = `taskview-packages/taskview-db-schemas/src/schemas/`. Las referencias de backend indican el archivo de rutas y la clase que realiza la operación; sus controladores están en el mismo módulo.
